# Security policy

## Supported version

Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use this
repository's **Security** tab and select **Report a vulnerability** to open a
private report. If that option is unavailable, contact the repository owner
through GitHub to request a private channel before sharing technical details.

Include the affected file or version, reproduction steps, impact, and any
suggested mitigation. Do not test against third-party accounts, live provider
credentials, or data you do not own; the synthetic fixture is the approved test
surface.

Reports will be acknowledged after review. Confirmed issues will be prioritized
by exploitability and impact, then fixed and disclosed through a GitHub security
advisory when appropriate.
